# CAD

The dragon head is modeled in Onshape:

[Open the Onshape document](https://cad.onshape.com/documents/04c386242416f52d20d963e8/w/17ca853073e346cce2480dec/e/b78fc263b8e5c9a841a25753?renderMode=0&uiState=6ab5e71f1fdec7f42ea53b89)

## Files

- [`dragon-head-assembly.step`](dragon-head-assembly.step): the full assembly, exported from Onshape. Open it in any CAD program to inspect or edit the individual parts.
- [`dragon-head-all-pieces.stl`](dragon-head-all-pieces.stl): a mesh of all the head pieces, for 3D printing.

## Re-exporting the STEP file from Onshape

If you change the design, export it again:

1. Open the document above and switch to the **Assembly** tab.
2. Right-click the assembly tab at the bottom of the window and choose **Export**.
3. Set the format to **STEP** and export.
4. Save the downloaded file over `dragon-head-assembly.step` in this folder.
